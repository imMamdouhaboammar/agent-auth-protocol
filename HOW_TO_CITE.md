# How to Cite AgentAuth

## Preferred human-readable citation

**Mamdouh Aboammar. AgentAuth Protocol v0.2: System Design for AI Agent
Identity, Authentication, Authorization, Delegation, Federation, and
Attestation. 2026.**

Canonical source:
https://github.com/imMamdouhaboammar/agent-auth-protocol

## Short citation

```text
Aboammar, M. (2026). AgentAuth Protocol v0.2.
https://github.com/imMamdouhaboammar/agent-auth-protocol
```

## Implementation attribution

When AgentAuth is used as the design basis for an implementation, the project
requests a source note such as:

```text
Based on the AgentAuth Protocol system design:
https://github.com/imMamdouhaboammar/agent-auth-protocol
Original system design by Mamdouh Aboammar.
```

## Machine-readable citation

GitHub reads [CITATION.cff](CITATION.cff) and can expose a "Cite this
repository" action on the repository page.

## Version citation

When citing a specific design state, prefer a release tag or commit SHA in
addition to the repository URL so the referenced semantics remain reproducible.
