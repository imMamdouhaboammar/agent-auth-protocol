# AgentAuth Attribution Policy

## Canonical attribution

When the AgentAuth specification or documentation is quoted, reproduced,
translated, adapted, summarized into a derivative specification, or otherwise
shared in a way covered by CC BY 4.0, use attribution substantially equivalent
to:

> AgentAuth Protocol, original system design by Mamdouh Aboammar.  
> Canonical source: https://github.com/imMamdouhaboammar/agent-auth-protocol  
> Documentation licensed under CC BY 4.0. Changes were made, if applicable.

A machine-readable citation is available in [CITATION.cff](CITATION.cff).

## For implementations built from this specification

If you build software using the AgentAuth system design as a direct technical
reference, the project requests that your implementation documentation include:

```text
Implements or is inspired by the AgentAuth Protocol system design:
https://github.com/imMamdouhaboammar/agent-auth-protocol
Original system design by Mamdouh Aboammar.
```

This implementation attribution request is intended to preserve technical
provenance and make the origin of the design discoverable.

The legal requirement depends on what material you actually reuse. Independent
implementation of general ideas may not, by itself, create a copyright
attribution obligation. Reproducing or adapting licensed AgentAuth
documentation remains subject to the applicable license.

## For research, articles, and technical comparisons

Preferred short citation:

> Mamdouh Aboammar, *AgentAuth Protocol v0.2*, 2026.  
> https://github.com/imMamdouhaboammar/agent-auth-protocol

For formal citation, use [CITATION.cff](CITATION.cff).

## For copied diagrams

Keep the creator, source repository, and CC BY 4.0 license notice close to the
diagram where practical.

Example:

```text
Source: AgentAuth Protocol by Mamdouh Aboammar
https://github.com/imMamdouhaboammar/agent-auth-protocol
CC BY 4.0, adapted
```

## For modified specification text

State that the material was modified.

Do not present a modified specification as an official AgentAuth release unless
the AgentAuth project explicitly published it.

## No endorsement

Attribution must not imply that Mamdouh Aboammar or the AgentAuth project
endorses a derivative implementation, product, company, service, or claim.

## Third-party material

The repository references standards and external projects. AgentAuth
attribution does not replace attribution or license obligations that may apply
to third-party material.
